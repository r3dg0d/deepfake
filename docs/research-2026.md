# Research review through October 1, 2026

Reviewed primary papers, official repositories, model-license records and specifications. “Not measured” means no local performance or quality claim; published throughput on other GPUs is not an RTX 4090 result. The current runtime remains AlphaFace plus independently implemented mask/composite adapters. No research model is silently substituted.

## Swapping and cinematic video

| Method / date | Primary paper and implementation | Licensing / availability | Mechanism and relevance | Local evaluation / decision |
|---|---|---|---|---|
| AlphaFace / Jan 2026 | [Paper](https://arxiv.org/abs/2601.16429), [code](https://github.com/andrewyu90/Alphaface_Official) | MIT code; Drive weight redistribution license undocumented | Existing identity swap; pose robustness does not replace a foreground mask | Actual CUDA/BF16 webcam, replay and offline runs; retained backend; cached source encoding. Baseline 720p swap capacity 33.5 FPS, new 30.6 in the synthetic benchmark; additional masks have a cost |
| VFace / WACV 2026 | [Paper](https://arxiv.org/abs/2602.07835), [code](https://github.com/Sanoojan/VFace) | MIT repository; Paint-by-Example derivatives Open RAIL-M; released checkpoint CC BY-NC 4.0 / dataset restrictions | Frequency-aware temporal attention, target-structure attention and flow-based smoothing in a diffusion swapper | Paper/code review only. Attention injection cannot be bolted into AlphaFace. Adopted the general motion-aware mask/color stabilization principle, not claimed to implement VFace. Speed, VRAM and identity scores not measured |
| REFace / WACV 2025 | [Official code and paper links](https://github.com/Sanoojan/REFace) | MIT wrapper, inherited CreativeML Open RAIL-M restrictions | Reference-guided diffusion face editing; can include hair/accessories | Review only; not run/downloaded. Replacing target accessories conflicts with foreground preservation. Potential offline research dependency; no measured 4090 budget |
| DynamicFace / ICCV 2025 | [Project](https://dynamic-face.github.io/), [paper](https://arxiv.org/abs/2501.08553) | Official page still says code coming soon; no verified distributable implementation/license | Composable 3D facial priors, identity attention and temporal diffusion | Review only. Promising pose/identity control, but not a verified installable backend. No local FPS, VRAM, identity or occlusion measurements |
| FaceDancer / WACV 2023 | [Official repository / paper links](https://github.com/felixrosberg/FaceDancer) | CC BY-NC-SA 4.0; TensorFlow checkpoint stack | Attribute-preserving identity injection and occlusion-aware architecture | Reviewed architecture; not loaded. Its design reinforces separating identity and target attributes. Backend conversion and quality validation remain outstanding |
| LivingSwap / CVPR 2026 | [Project](https://aim-uofa.github.io/LivingSwap/), [paper](https://arxiv.org/abs/2512.07951) | Official page: code coming soon; no verified runtime license/weights | Video reference guidance, identity keyframes and chunk-to-chunk temporal stitching for cinematic footage | Reviewed, not run. Source-video realism is relevant, but an unavailable/unmeasured backend cannot justify a `cinematic` flag. No local FPS/VRAM or cinematic quality claim |

`quality` is an actual offline path with full-rate parsing, color-state stabilization and bidirectional flow. A diffusion `cinematic` preset is deferred until distributable checkpoints, a reviewed license, reproducible identity/temporal comparisons and a measured 4090 memory budget exist. Slower processing alone is not evidence of better output.

## Detection, segmentation and tracking

| Method / date | Primary sources | License / assets | Occlusion and temporal behavior | Local evaluation / decision |
|---|---|---|---|---|
| YuNet / 2023 model | [OpenCV model and license](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | MIT; 0.233 MB ONNX | Five landmark positions and detection confidence; no occlusion matte | Installed and hashed; adapter's confidence-column bug fixed. Runs on a ≤480 px image. Used for stable tracked face boxes |
| BiSeNet / ECCV 2018; RN18 implementation | [Paper](https://arxiv.org/abs/1808.00897), [implementation](https://github.com/yakhyo/face-parsing) | MIT code/model; CelebAMask-HQ dataset terms; ONNX 53.2 MB | Face classes separate hair/eyewear/background; single-frame parser needs temporal association | CUDA IO binding avoids copying the full logits to CPU. Parser every second realtime frame, every quality frame; combined engine measured roughly 7–10 ms at 256 px. Installed explicitly |
| XSeg / DeepFaceLab lineage | [Model license catalog](https://docs.facefusion.io/introduction/licenses), [upstream](https://github.com/iperov/DeepFaceLab) | Model GPL-3.0; ONNX 70.3 MB; not bundled; FaceFusion wrapper has a separate license and was not copied | Lightweight visible-face evidence excluding occluders; refreshed every crop so a new foreground object can win immediately | Used with BiSeNet. Original asymmetric operators took 16.42 ms; equivalent in-memory rewrite measured 2.65 ms for XSeg alone. Combined fixture benchmark recorded separately |
| SAM2 / Jul 2024 | [Paper](https://arxiv.org/abs/2408.00714), [code/checkpoints](https://github.com/facebookresearch/sam2) | Apache-2.0 code and checkpoints, repository exceptions noted upstream | Streaming memory, interactive video masks; prompt association/recovery useful for persistent objects | Reviewed; not downloaded or benchmarked. Prompt selection and additional memory/inference cost require a separate integration, not a claimed realtime fallback |
| SAM-MT / Jul 9 2026, ECCV 2026 | [Paper](https://arxiv.org/abs/2607.08688), [official code](https://github.com/FudanCVL/SAM-MT) | Inference/checkpoint listed; no clear root LICENSE found in reviewed repository; training release remains TODO | Individual/global representations, efficient multi-target queries and sparse-memory handling of occlusion | Review only. Authors report 36+ FPS for ten targets on **RTX A6000**; not a local 4090 measurement. No copy, download or runtime activation pending license and performance verification |
| LK tracking + Farneback / OpenCV | [Official flow tutorial](https://docs.opencv.org/4.x/d4/dee/tutorial_optical_flow.html) | OpenCV Apache-2.0; no weights | Forward/backward feature rejection, robust box motion; backward dense mask transport | Actual per-track implementation; often ~2–3 ms tracking in 640×480 replay. Framewise XSeg still supplies fresh occluder evidence. Chosen for predictable low overhead |

The reviewed foundation methods could improve long occlusions, but mask propagation alone cannot discover a new foreground object. The implemented fast path combines semantic parsing, current visibility, motion and conservative fallback. [Architecture](architecture/occlusion.md) and [measurements](benchmarks/2026-10-01.md) detail thresholds, known masks and limitations.

## Flow, depth and restoration

| Method / date | Primary sources | License | Local test / resource claim | Decision |
|---|---|---|---|---|
| RAFT / ECCV 2020 | [Official code and paper](https://github.com/princeton-vl/RAFT) | BSD-3-Clause | Reviewed recurrent all-pairs flow; not downloaded, no 4090 FPS/VRAM measurements | Candidate for offline mask warping; did not replace cheap crop flow without a measured accuracy benefit |
| GMFlow / CVPR 2022 | [Official code and paper](https://github.com/haofeixu/gmflow) | Apache-2.0 | Reviewed global matching and forward/backward consistency. Published 26 ms on A100 at 436×1024 is upstream, not our measurement | Adopted matched-coordinate consistency principle in NVOFA; no claim to execute GMFlow |
| NVIDIA Optical Flow / driver API | [SDK](https://github.com/NVIDIA/NVIDIAOpticalFlowSDK) | Vendored API headers BSD-3-Clause; host proprietary driver runtime | Actual NVOFA + CUDA resampling. Known 12 px translation: midpoint MAD 20.683 before sign correction, 1.531 after. 640×480 replay ~6.4 ms per generated frame | Used; transports original pixels and visibility in the same warp, guards after sharpening; quality enables backward flow |
| Depth Anything V2 / NeurIPS 2024 | [Official repository and paper links](https://github.com/DepthAnything/Depth-Anything-V2) | Small Apache-2.0; Base/Large/Giant CC BY-NC 4.0 | Reviewed monocular depth; no local inference measurements | Depth can inform ordering, but does not resolve contact boundaries or thin glasses by itself. Not activated without an ablation showing improvement over masks |
| CodeFormer / NeurIPS 2022 | [Official repository / paper](https://github.com/sczhou/CodeFormer), [license](https://github.com/sczhou/CodeFormer/blob/master/LICENSE) | S-Lab License 1.0, non-commercial | Reviewed codebook restoration; not downloaded or benchmarked | Restoration can change identity and texture across frames. No automatic restoration without identity/temporal validation |

Actual process Torch allocations in synthetic 720p tests were about 1.4–1.65 GB. These exclude ONNX allocations and are not total GPU residency. Whole-device readings of about 11–12 GB included other desktop/model processes. Unexecuted alternatives have **unknown local** VRAM, latency, identity drift and occlusion accuracy; estimates are not disguised as benchmark results.

## Disclosure, watermarking and platforms

| Technology | Primary sources / license | Evaluation and decision |
|---|---|---|
| C2PA 2.4 / official CAI Python SDK | [Specification](https://spec.c2pa.org/specifications/specifications/2.4/specs/ContentCredentials.html), [SDK](https://github.com/contentauth/c2pa-python), [actions guidance](https://opensource.contentauthenticity.org/docs/manifest/writing/assertions-actions/) | c2pa-python 0.38.0 / core 0.91.0. Actual post-encode signing, signature validation, BMFF asset binding and tamper rejection tested. `compositeWithTrainedAlgorithmicMedia` classifies face replacement. Local signer is untrusted publicly; actions and original ingredient are embedded |
| Google SynthID | [Official product page](https://deepmind.google/models/synthid/), [public text implementation](https://github.com/google-deepmind/synthid-text) | Image/video embedding is tied to supported Google workflows; public text code is not a generic image/video embedder. No verified public general embedder for AlphaFace found. Detector availability does not imply an embedding API. Not implemented or claimed |
| Adobe TrustMark / arXiv 2023, ICCV 2025 | [Official implementation and license](https://github.com/adobe/trustmark), [paper](https://arxiv.org/abs/2311.18297) | MIT code **and weights**. Q encoder/decoder explicitly downloaded (65 MB), pinned, loaded with `weights_only=True`; remover is never loaded/exposed. Actual encode 7.64 ms and PSNR 43.62 dB on a fictional fixture. Per-frame image watermark, not a video-specific guarantee. [Codec stress results](provenance.md) include failures |
| VideoSeal / Dec 2024; later official models | [Official code/models](https://github.com/facebookresearch/videoseal), [paper](https://arxiv.org/abs/2412.09492) | MIT code/models. Reviewed temporal propagation and newer PixelSeal/ChunkySeal listings available by the review cutoff. Not downloaded or benchmarked; a video-native alternative worth testing before claiming superiority to TrustMark |
| X C2PA integration / Mar 2026 | [Official X statement](https://help.x.com/en/business-and-advertising/brand-safety/industry-leadership-and-partnerships), [authenticity policy](https://help.x.com/en/rules-and-policies/authenticity) | X describes C2PA detection/label integration. This does not promise acceptance of a local certificate or a label for every upload. No account posting/UI test performed. C2PA may be consumed at upload and absent from transcoded downloads; our local remux/transcode tests show removal |

The robust practical combination is verified C2PA for authenticated file disclosure, optional measured TrustMark for a pixel-level disclosure signal, and visible disclosure where signed file metadata cannot accompany the output. Neither watermark is an ownership proof or universal social-platform detector. No watermark removal or provenance stripping command is exposed.
