# RTX 4090 validation — October 1, 2026

Python 3.12, PyTorch 2.6.0+cu124, ONNX Runtime GPU 1.22.0, AlphaFace BF16 and NVIDIA optical flow. Raw anonymous measurements: [2026-10-01.json](2026-10-01.json). No private camera imagery, keys or model weights are included.

## Live and replay

A 20-second local camera test covered actual hand passes across the face, hair/headphones and head turns. The inspected hand/hair remained foreground, and out-of-view faces kept the original image. Cup, phone, microphone and glasses did not receive live ground-truth validation. The first live test ran during an accidentally CPU-saturating Nix build, producing many held frames; that performance is not represented as a clean benchmark.

After stopping that build, the same footage was replayed at 30 FPS for 15 seconds using a null sink, source-face warmup and a 120 ms latency budget. It finished at 30.3 processed FPS, 60.9 newly delivered FPS (short reporting window), 61.4 sink FPS, 450 keyframes, 446 generated frames, four held slots and four late frames. Steady windows were about 30/60 FPS. Latency ranged 60.2–88.7 ms; frame-generation cost was ~6.4 ms per generated frame. This is paced replay, not a second camera capture or a guaranteed future frame rate.

A separate actual camera-to-v4l2loopback run sustained ~30 processed / 60 presented FPS with ~64 ms latency. FFmpeg read back 30 frames from `/dev/video10` at **60/1 FPS**, 640×480 YUV420P. Quickshell QML logged `Configuration Loaded`, and an actual running instance was inspected. OpenCV's V4L2 consumer requests 30 FPS by default and changes the device rate; the readback used FFmpeg without a forced rate. Deepfake re-announces its rate after FFmpeg resets the output format.

## Synthetic pipeline comparison

Same fictional portrait, 720p, 30 FPS pacing and three-second measurements. Baseline is the preserved local pre-occlusion/NVOF implementation, not an invented comparison against proprietary software. The final run had a two-core-limited Nix build in the background; background applications also used the GPU.

| Metric | Before | 0.5.0 candidate |
|---|---:|---:|
| Crop swap capacity | 33.5 FPS | 30.6 FPS |
| Swap-stage median | 33.90 ms | 34.72 ms |
| Pipeline without FrameGen: input processed | 30.0 FPS | 30.1 FPS |
| Pipeline without FrameGen: end-to-end latency | 30.4 ms | 35.2 ms |
| 2× FrameGen: new output / latency | 48.6 FPS / 151.3 ms | 50.6 FPS / 129.4 ms |
| 3× FrameGen: new output / latency | 77.0 FPS / 141.1 ms | 88.9 FPS / 148.2 ms |
| Torch peak allocation, swap test | 1392 MB | 1411 MB |

Mask evidence and target/mask transport add work. They are justified by foreground correctness, not a blanket speedup claim. Runtime stage snapshots measured about 10 ms masks, 1.9 ms tracking and 3.7 ms compositing at 720p. Model confidence is not an accuracy percentage. Torch allocation excludes ONNX CUDA allocations; whole-GPU readings near 11–12 GB include unrelated applications.

The earlier September FrameGen benchmark predates these mask protections. Full 2×/3× throughput, held/late counts and allocation values for baseline and final runs are included in JSON. Output FPS counts new key/generated frames; sink FPS can additionally include held repeats. Short-window measurements can briefly exceed the nominal pacing rate.

## Known-mask foreground benchmark

A fictional portrait receives stylized moving shapes (18 frames per type, 126 moving frames total), with known overlay masks. The substitute face has a contrasting fixed color, so foreground pixel leakage is observable. The comparison isolates mask/compositor behavior; it is not an AlphaFace identity-score comparison or a real-object dataset. The five-panel local clip displays original, old oval composite, visible composite, face mask and withheld-face mask.

| Foreground | Mask IoU | Old leak fraction | New leak fraction | Visible face retained | Boundary F1 ±2 px | Mask p50 ms |
|---|---:|---:|---:|---:|---:|---:|
| Hand | .7766 | 1.0000 | 0 | .8352 | .3997 | 8.59 |
| Hair | .7529 | 1.0000 | 0 | .9522 | .3275 | 7.63 |
| Glasses | .4127 | 1.0000 | 0 | .9058 | .3166 | 7.60 |
| Microphone | .6515 | .9444 | 0 | .9604 | .3938 | 7.37 |
| Cup | .7738 | 1.0000 | 0 | .8556 | .3423 | 7.43 |
| Phone | .8390 | 1.0000 | 0 | .8764 | .5322 | 7.54 |
| Full cover | 1.0000 | 1.0000 | 0 | 0 | 1.0000 | 6.64 |

IoU measures withheld support inside the baseline visible face, including conservative safety margins and parser exclusions. Thin glasses have the weakest IoU/boundary results: no leakage on these fixtures is achieved partly by retaining extra original pixels. It does not mean perfect fine-detail segmentation. Boundary F1 uses two-pixel tolerance. Twelve repeated static frames per fixture had mean alpha delta zero at the recorded precision; moving-alpha delta includes actual motion and is not a flicker score.

GPU tests independently verify a known translation's resampling direction and target foreground preservation after interpolation/sharpening. A 12 px translation experiment reduced midpoint MAD from 20.683 to 1.531 after the flow-sign fix. CPU ONNX tests verify the asymmetric-convolution rewrite, and malformed/non-finite model output falls back to original pixels.

## Exports and disclosure

The quality export processed 60 source frames at 30 FPS into 60 keyframes, 59 generated frames and one final held frame: **120 total / 60 FPS / 2.000 seconds**, with 2.000 seconds of original audio. A native-rate partial export retained 10 frames at 30 FPS and 640×640, with 0.333333 seconds of video and 0.341333 seconds of packet-bounded audio.

C2PA verified the encoded artifact's signature and BMFF binding; development signer public trust remained false. TrustMark decoded the expected disclosure in all ten sampled encoded frames. Tampering with signed `mdat` data fails integrity validation.

[Provenance stress tests](../provenance.md) cover H.264, AV1, low bitrate, crop, resize, frame-rate conversion and metadata remux. Aggressive 300 kbps compression defeated the invisible watermark. Ordinary transcoding/remux removed C2PA. There is no social-platform-label guarantee, no cinematic diffusion benchmark and no calibrated identity/LPIPS study in this release.
