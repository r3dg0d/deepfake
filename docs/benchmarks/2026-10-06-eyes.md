# Eye-detail update — 0.5.1rc4

The attached screenshot showed soft eyelid and iris edges. AlphaFace outputs 256×256 face crops, which were enlarged with bilinear sampling. Some detail is lost in synthesis itself; this update does not reconstruct missing iris texture or claim to repair every source photograph.

Changes:

- Area downsampling for larger target/source face crops; cubic sampling for enlargement and pasted faces.
- Current-frame BiSeNet classes 4/5 identify the target eye locations, from the same inference as face/mouth masks. Generated eyes receive a mild luminance-only unsharp residual with a two-level noise threshold, six-level correction cap and local-extrema clamp. The algorithm never copies target eyes or downloads a restoration model.
- Eye regions intersect current visible alpha. The final composite still has zero opacity on declared occluders. Mouth preservation and virtualcam label settings are retained.

Local GPU checks replayed the attached screenshot and two frames of the existing private clip with two existing source photos (the user's earlier source and the fictional benchmark face). The screenshot is already processed media; reprocessing it is a diagnostic, not a ground-truth reconstruction of the original live capture. Before/after eye close-ups showed a modest improvement in edge definition. Severe yaw samples still preserve the original face, which is expected fallback rather than an eye-detail improvement.

Validation: 87 CPU/runtime regression tests, two separately selected GPU tests, Ruff lint/format and Nix build. New tests verify increased edge contrast without overshoot, unchanged flat/noisy regions, current eye-region visibility and exact foreground retention after enlargement. The Nix environment omits two optional provenance tests, while those tests run in the installed runtime.

No new model downloads or global Python packages. Source-specific softness may require a better source photo or a higher-resolution trained swapper; bounded sharpening cannot recover detail the 256-pixel model did not generate.
